Sélectionnez une région (outil Sélection) ou copiez-la (Ctrl C), puis enregistrez-la sous un nom : c’est un modèle réutilisable (tuiles et décors). « Coller » agit comme Ctrl V : aperçu, clic pour valider, annulable. Pour modifier un modèle, collez-le, retouchez-le, puis ré-enregistrez la région sous le même nom.
