Vue

Molette : zoom centré sur le curseur — clic milieu, clic droit ou Espace+glisser : déplacer la vue — mini-carte cliquable — Maj+glisser : rectangle de tuiles — Alt+clic : pipette (reprend la tuile ou le décor visé) — Ctrl+Z / Ctrl+Maj+Z : annuler/rétablir. Outils de dessin dans le rail de gauche, palette et calques à droite. En zoom rapproché, la carte est dessinée avec les vrais sprites du jeu. Les modifications s'appliquent à chaud sur le serveur et au prochain chargement de zone pour les joueurs.

Sélectionnez une région (outil ⧉, glisser) ou copiez-la (Ctrl+C), puis enregistrez-la sous un nom : c'est un template réutilisable (tuiles + décors).
« Coller » l'arme comme Ctrl+V (aperçu fantôme, clic pour valider, annulable).
Modifier ensuite : collez un template, retouchez-le sur la carte, re-sélectionnez la région et ré-enregistrez sous le même nom pour l'écraser.
