Atelier matériaux — murs, toits et sols depuis une texture

Chargez une texture carrée tuilable (photo de matériau CC0 — ex. ambientCG —, ou image IA générée en mode « tiling » — ex. Leonardo). L'atelier fabrique les pièces de jeu : murs d'arête (compatibles avec l'outil de tracé ▦ de l'éditeur), pans de toit, ou dalles de sol sans couture. La structure (projection isométrique, orientation, ancres) est calculée par le code ; la texture apporte le rendu. Pensez à créditer la source dans CREDITS.txt.
