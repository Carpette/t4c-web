Guide de l'Aventurier

Contrôles de Base :

  • Clic Gauche : Se déplacer, attaquer, ramasser, ou parler à un PNJ.
  • Clic Droit : Annuler la visée d'un sort actif.
  • Molette : Zoomer ou dézoomer la caméra.
  • Maintenir Ctrl : Mode Combat (tous les clics attaquent ou lancent un sort).
  • Double-clic Titre : Recentrer les fenêtres déplaçables.

Raccourcis Système :

I : Inventaire
C : Fiche Personnage
S : Livre des Sorts
H : Ce Guide d'Aide
P : Potion de Vie
M : Potion de Mana
Entrée : Activer le Chat
Échap : Menu / Annuler

Vos Raccourcis de Sorts :

Aucun sort assigné. Ouvrez votre livre des sorts (S) pour en lier un à une touche.
